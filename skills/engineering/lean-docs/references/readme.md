# README

A useful README answers: what it is, how to install, one usage command, license.

| Heading | Flag when missing | Add |
|---------|-------------------|-----|
| Title/what | No first paragraph | One sentence purpose |
| Install | No clone/pip/npm | One block |
| Usage | No command or example | One command |
| License | No LICENSE pointer | Link `LICENSE` |

Do not generate badges, screenshots, or a 20-section template unless asked.
